使用说明
  1. 支付宝 App → 我的 → 账单 → 右上角"…"→ 导出/开具交易流水 → 选时间 → 邮箱下载（CSV）。
  2. 微信 → 我 → 服务 → 钱包 → 账单 → 右上角"…"→ 下载账单 → 选时间 → 邮箱下载。
  3. 把下载的文件导入本页即可。每月导一次，不会重复。
  4. iPhone Safari 打开本页 → 分享 → "添加到主屏幕" 像 APP 一样用。
